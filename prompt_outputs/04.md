Phase 04 Heatmap Engine Implementation:
- Implemented state-isolated, deterministic numeric spatial aggregation engine in src/genevac/analytics/heatmap.py.
- Maintained 100% backwards compatibility for existing HeatmapCalculator in src/genevac/analytics/__init__.py.
- Independent layers:
  1. Occupancy Count: Integer array [row, col] counting distinct valid agents per cell per snapshot.
  2. Physical Density: Float array [row, col] in peds / m^2 (derived as occupancy / (cell_w * cell_h)).
  3. Dwell Time: Float array [row, col] accumulating agent-seconds per cell over observation intervals.
  4. Min-Max Normalization: Optional derived view scaled to [0.0, 1.0] without modifying raw physical layers.
- Geometry & Boundary conventions:
  - Top-left origin, +X right (east), +Y down (south), spatial units: meters.
  - Half-open indexing: [min_x + col*w, min_x + (col+1)*w) and [min_y + row*h, min_y + (row+1)*h).
  - Maximum outer boundary inclusion: Points exactly on max_x or max_y map to final valid column/row.
  - Out-of-bounds policy: Strictly out-of-bounds coordinates are rejected, quarantined, and recorded in rejection_reasons diagnostics without corrupting valid observations.
