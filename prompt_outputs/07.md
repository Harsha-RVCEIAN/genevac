## B. Baseline Implementation (`ConstantVelocityPredictor`)

1. **Methodology:**
   - Implemented in `src/genevac/prediction/baseline.py`.
   - Pure kinematic velocity estimation using actual timestamps from the last two valid observations:
     $$v_x = \frac{x_{\text{last}} - x_{\text{prev}}}{t_{\text{last}} - t_{\text{prev}}}, \quad v_y = \frac{y_{\text{last}} - y_{\text{prev}}}{t_{\text{last}} - t_{\text{prev}}}$$
   - Extrapolates future positions directly from the authoritative last position $p_{\text{last}}$, eliminating cumulative numerical roundoff drift:
     $$p_{\text{fut}}(k) = p_{\text{last}} + \mathbf{v} \cdot (t_{\text{fut}}(k) - t_{\text{last}})$$
2. **Defensive Preconditions:**
   - Strictly enforces minimum history requirement ($N \ge 2$).
   - Rejects non-positive time deltas, non-finite coordinates, and future observations ($t_{\text{obs}} > t_{\text{ref}} + 10^{-9}\text{ s}$).
   - Enforces `max_observation_age` staleness limits.
   - Batch prediction isolates failures into per-agent `TrajectoryValidationError` instances without interrupting valid agent forecasts.
3. **Assumptions & Limitations:**
   - Assumes zero acceleration ($\mathbf{a} = 0$).
   - Unconstrained by physical room walls or obstacles.
   - Generates a single deterministic path with zero representation of tactical motion indeterminacy.

## C. Evacuation MID Implementation & Repairs

All 12 required architectural and numerical repairs were implemented and verified in `src/genevac/prediction/mid.py`:

1. **Per-Sample Guidance Independence:**
   - Guidance is now calculated independently for every generated trajectory sample $k \in \{0, \dots, K-1\}$ using that sample's exact simulated coordinates. Sample 0's guidance field is never reused for other samples.
2. **Deterministic Obstacle Repulsion & Escape:**
   - For points outside obstacles, standard inverse-square repulsion applies.
   - For points inside an obstacle bounding box ($[x_{\min}, x_{\max}] \times [y_{\min}, y_{\max}]$), the model computes the distance to all 4 boundary faces ($x - x_{\min}, x_{\max} - x, y - y_{\min}, y_{\max} - y$) and emits a deterministic outward normal escape unit vector toward the closest face with corner tie-breaking.
3. **Numerical Stability & Force Capping:**
   - All guidance vector calculations incorporate numerical stability tolerances ($\epsilon = 10^{-4}$) and are strictly clamped to a maximum acceleration magnitude $F_{\max} = 5.0\text{ m/s}^2$. All outputs are verified finite (`torch.isfinite`).
4. **Physical Guidance Documentation:**
   - Documented accurately as an independent per-sample potential field combining exit attraction, obstacle repulsion/escape, kinematic inertia, and physical room boundary clamping.
5. **Trained vs. Untrained Model Tracking:**
   - Model state tracks its training provenance explicitly via `is_trained`, `training_sample_count`, `training_epochs_completed`, and `is_trained_model` on prediction containers.
6. **Isolated RNG Without Global Side Effects:**
   - Sampling and training use a local, isolated `torch.Generator(device)` and NumPy `np.random.default_rng(seed)`. Global PyTorch or NumPy random states (`torch.manual_seed`, `np.random.seed`) are never modified.
7. **Strict 16-Feature Ordering & Canonical Normalization:**
   - Conditioning vectors strictly follow the canonical 16-element feature schema (`FEATURE_NORMALIZATION_SCALES`). Both training (`fit`) and inference (`predict_samples`) consume the identical `normalized_vector`.
8. **Strict Target Exit Validation:**
   - If `target_exit_id` is specified, it must exist in `environment.exits`. If absent, `TrajectoryValidationError` is raised immediately. Silent fallback or exit substitution is strictly prohibited.
9. **Consistent Horizon Handling:**
   - Predictor validates $1 \le H \le H_{\text{cfg}}$ and slices the generated displacement tensor to the exact requested horizon. Non-positive or oversized horizons raise `ValueError`.
10. **Point Walkability vs. Segment Collision Detection:**
    - In addition to point walkability, segment collision detection is implemented via the Liang-Barsky parametric line-clipping algorithm (`line_segment_intersects_box`), evaluating consecutive steps along each path against obstacle boxes. Both `point_walkability` and `segment_collision_free` rates are reported.
11. **Training Pipeline with Loss Masking:**
    - Training loop (`train_step` and `fit`) uses an explicit binary loss mask $M \in \{0, 1\}^{B \times H \times 1}$ for unobserved future steps, eliminating silent point duplication. Samples with invalid histories are tracked with explicit diagnostic messages.
12. **Stochastic Evaluation Reporting:**
    - Returns `oracle_best_of_k_ade`, `oracle_best_of_k_fde`, `expected_mean_of_k_ade`, `expected_mean_of_k_fde`, `mean_diversity`, `point_walkability`, `segment_collision_free`, `evaluated_samples`, `failed_samples`, and `skipped_samples`.
