## 1. Principles of Honest Scientific Comparison
When presenting results comparing evacuation scenarios, downstream analysts must uphold three core principles:
1. **Preserve Per-Run Granularity:**
   Aggregate statistics (mean, median, standard deviation) summarize performance, but individual run records must remain inspectable to identify outliers, crashes, and early terminations.
2. **Explicit Comparability:**
   Never present numbers in a comparison table without documenting whether the time window, population, and spatial domain are equivalent.
3. **Traceability to Configuration Provenance:**
   Every scenario is stamped with a cryptographic SHA-256 configuration fingerprint. Two runs cannot be claimed identical unless their configuration fingerprints match.

---

## 2. Limitations of Current Simulation Dynamics

1. **Kinematic Determinism & Seed Invariance:**
   - The simulation engine in `src/genevac/simulation/__init__.py` updates pedestrian positions according to linear velocity kinematics without an active pseudorandom number generator (PRNG).
   - Consequently, running the same scenario multiple times with identical initial conditions produces zero variance ($\sigma = 0.0\text{ s}$).
   - Multi-run variance will only emerge if initial positions or desired velocities are generated by an upstream stochastic placement model.
2. **Discrete Exit Event Availability:**
   - The engine does not emit discrete exit event timestamps during stepping. `exit_throughput` is therefore truthfully reported as `UNAVAILABLE` rather than estimated from disappearance.
3. **Single-Run Statistical Reporting:**
   - When only $N = 1$ run is executed for a scenario, sample standard deviation is mathematically undefined. In accordance with Phase 06 rules, standard deviation is set to `None` and labeled as a single-run observation.

---

## 3. Disallowed Practices
- **No Composite Ranking:** Generating arbitrary weighted sums (e.g. $0.4 \cdot \text{time} + 0.6 \cdot \text{density}$) to declare a "best" scenario is strictly prohibited.
- **No Synthetic ERSI / Delta Score:** Undefined metrics remain blocked until an authoritative scientific specification is provided by project leadership.
- **No Causal Overreach:** If multiple factors differ between scenarios (e.g., exit width and agent count changed simultaneously), the comparison must be labeled exploratory and avoid single-variable causal attribution.
