# Experimental Methodology

## Workflow
1. **Scenario Definition**: Configure initial agent distributions, exit widths, and obstacle locations.
2. **Monte Carlo Executions**: Run simulations across multiple random seeds to establish statistical significance.
3. **Comparison Matrix**:
   - Baseline flow vs. Obstacle-mitigated flow.
   - Ground truth simulation vs. AI-predicted trajectory accuracy across varying crowd densities.
4. **Export & Reporting**: Automated generation of summary statistics, charts, and spatial heatmaps.
